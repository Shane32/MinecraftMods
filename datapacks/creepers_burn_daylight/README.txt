Creepers Burn in Daylight Datapack (Minecraft 1.21.x)

What it does:
- Creepers ignite when exposed to daylight similar to zombies/skeletons.
- Runs once per second for lower server overhead.

Install:
1. Place this ZIP into:
   <server>/<level-name>/datapacks/
2. Run /reload or restart the server.
3. Verify with /datapack list.

Disable:
/datapack disable "file/creepers_burn_daylight"
Then run /reload.

Notes:
- Works on vanilla or Fabric servers.
- No mods required.
